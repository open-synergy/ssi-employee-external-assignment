# View External Assignments — Employee External Assignment Agreement Payment Term

## Pre-Condition

- At least one External Assignment is already loaded on the record (the button is only
  available once the **External Assignments** field is not empty).
- User has access to view Employee External Assignments.

## Flow

1. Open the **Human Resource > Career Management > External Assignment > Payment Terms**
   menu.
2. Open the record.
3. Go to the **Included Assignments** tab.
4. Click the **External Assignments** button (list icon).

## Post-Condition

- A list view opens showing the Employee External Assignments linked to this Payment
  Term.
