# Generate Agreements — Employee External Assignment Agreement Batch

> **Module:** ssi_employee_external_assignment_agreement\
> **Model:** `employee_external_assignment_agreement_batch`\
> **Menu:** Human Resource > Career Management > External Assignment > Agreement
> Batches\
> **Actor:** user in group `Employee External Assignment Agreement Batch / User`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The batch already exists and its status is not **Done**, **Cancelled**, or
  **Terminated** — the **Generate Agreements** button is hidden in those three statuses.
- **Data:** A receivable account (`account.account`) and a journal (`account.journal`)
  exist to apply to the generated agreements.
- **Access:** User is in group `Employee External Assignment Agreement Batch / User`
  (grants create access on the **Generate Agreement from Batch** wizard).

## Flow

1. Open the **Human Resource > Career Management > External Assignment > Agreement
   Batches** menu.
2. Open the batch record.
3. Go to the **Agreements** tab.
4. Click the **Generate Agreements** button.
5. In the wizard that appears, fill in:
   - **Number of Agreements** _(required)_: Defaults to **1**. Number of identical
     agreements to generate when no line is added to **Agreements** below.
   - **Receivable Account** _(required)_: Select the receivable account applied to every
     agreement generated by this run.
   - **Journal** _(required)_: Select the journal applied to every agreement generated
     by this run.
   - **Agreements** (optional): Add one line per agreement to generate instead of
     relying on **Number of Agreements**. Repeat the following steps as many times as
     needed:
     - Click **Add a line**.
     - Fill in each line with:
       - **Title**: Title for that agreement. Defaults to the batch's **Title** when
         left empty.
       - **Location**: Location for that agreement. Defaults to the batch's **Location**
         when left empty.
6. Click **Generate**.
7. Click **OK** on the confirmation dialog.

## Post-Condition

- New Employee External Assignment Agreement records are created in **Draft** status,
  linked to the batch. Each one's **Type**, **Partner**, **Contact**, **Location**,
  period (**Date**, **Date Start**, **Date End**), **Currency**, and **Pricelist**
  follow the batch — except a line's own **Location**, which overrides the batch's when
  filled.
- The number of agreements created equals the number of **Agreements** lines filled in,
  or the **Number of Agreements** value when no line was filled in.
- A list view opens showing the newly generated agreements.
- The count on the **Agreements** smart button increases accordingly.
