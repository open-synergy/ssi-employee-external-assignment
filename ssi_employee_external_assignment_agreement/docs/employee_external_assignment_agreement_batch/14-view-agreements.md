# View Agreements — Employee External Assignment Agreement Batch

## Pre-Condition

- None. The **Agreements** smart button is available regardless of status.

## Flow

1. Open the **Human Resource > Career Management > External Assignment > Agreement
   Batches** menu.
2. Open the record.
3. Click the **Agreements** smart button.

## Post-Condition

- A list view opens showing the Employee External Assignment Agreements linked to this
  batch.
