# Delete Employee External Assignment Type

## Pre-Condition

- The record is not referenced by any Employee External Assignment record.

## Flow

1. Open the **Human Resource > Configuration > Career > External Asssignment Types**
   menu.
2. Open the record to delete.
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.
5. Click the **External Asssignment Types** breadcrumb to return to the list.

## Post-Condition

- The record is permanently removed from the system.
- The list view no longer shows the deleted record.
